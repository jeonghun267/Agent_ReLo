# ReLo — 기능

ReLo로 **무엇을 할 수 있는지**를 **앱**과 **웹**으로 나누고, 그 안에서 화면 · 흐름별로 정리했습니다. (2026-11-16 기준)

- 어떤 기술로 만들었는지는 → [기술](./README_TECH.md)
- 코드가 어디에 있고 무엇을 맡는지는 → [파트별](./README_PARTS.md)

## 한 줄로

해외 직구 반품 · 교환 · AS를 **신청 → 쇼핑몰에 메시지 → 답장 확인 → 실제 입금 확인**까지 한 사람이 끝까지 따라가도록 돕습니다.

| | 앱 | 웹 |
|---|---|---|
| 시작 | 홈이 곧 대화 화면. 도우미 "말랑이"에게 부탁 | 첫 화면의 버튼 하나로 신청 시작 |
| 신청 | 5단계, 한 화면에 질문 하나 | 5단계 |
| 영수증 넣기 | 찍기 · 고르기 · 다른 앱에서 공유받기 | 파일 올리기 · 끌어다 놓기 |
| 마감 알림 | 기기 알림 (안드로이드) | 없음 |
| 로그인 | 이메일 + 비밀번호 | 이메일 + 비밀번호, 구글 · 패스키(설정값을 넣으면) |
| 언어 | 한국어 · 영어 · 일본어 · 중국어 | 한국어 · 영어 · 일본어 · 중국어 |

## 앱

### 1. 시작과 홈

- **시작 연출**: 기기의 시작 화면에서 로고가 그대로 이어져 말랑이로 깨어나고, 상단 바의 로고 자리로 들어가면서 홈이 나옵니다 (1.3초).
- **홈 = 대화 화면**: 맨 위 파란 카드에 받을 돈을 크게 보여 주고, 그 아래 지금 할 일을 상자 없는 줄로 보여 줍니다. 맨 아래 입력칸으로 말랑이에게 부탁하면 그 아래로 대화가 쌓입니다.
- **처음 쓰는 사람**: 환불 건이 하나도 없으면 "무슨 일이 있었어요?"와 고르는 줄 세 개로 시작합니다. 하나를 고르면 그 내용이 채워진 신청 화면이 열립니다.
- 하단 탭은 **홈 · 내 환불 · 설정** 셋입니다.

### 2. 환불 신청 (5단계)

- 쇼핑몰 · 주문번호 → 상품 · 금액 → 해결 방법 · 사유 → 영수증 · 사진 → 동의 후 등록.
- **영수증으로 자동 채우기**: 고른 영수증을 서버의 AI가 읽어 칸을 채웁니다. 읽지 못하면 지어내지 않고 붙이기만 합니다.
- 사유를 한국어로 쓰면 외국어로 옮겨 줍니다.
- 금액 칸은 숫자와 소수점만 받고(자릿수는 통화에 맞춤), 날짜는 달력에서 고릅니다. 빠뜨린 것은 그 칸 아래 빨간 글자로 알립니다.
- 신청을 마치면 지구본이 앞으로 나오고 그 나라에서 비행기가 출발합니다.

### 3. 영수증 · 사진 (안드로이드)

- **붙이기**: 사진 찍기 · 사진첩에서 고르기 · 파일(PDF)에서 고르기. 파일당 10MB.
- 사진은 바로 세우고 줄인 뒤, 촬영 위치 같은 덧붙은 정보를 지우고 올립니다.
- **공유로 시작하기**: 메일 · 사진첩 · 쇼핑몰 앱에서 "공유 → ReLo"로 넘기면 그 파일이 붙은 채로 신청이 열립니다. 메일함이나 쇼핑몰 계정을 앱에 연결하지 않습니다.

### 4. 내 환불

- 맨 위에서 말랑이가 한 줄로 요약하고, 받을 돈 / 받은 돈을 보여 줍니다.
- 필터 셋(전체 · 진행 중 · 입금 완료), 검색, 휴지통.
- **환불 통장**: USD · JPY · CNY · EUR · KRW · GBP · CAD · AUD 8개 통화를 따로 집계합니다.

### 5. 환불 상세

- 맨 위에 받기로 한 돈 / 받은 돈과 지금 단계.
- 글자 탭 넷: **메시지 · 답장 · 입금 · 기록**. 화면을 열면 지금 할 일이 있는 탭이 켜져 있습니다.
- **쓴 메시지 바로 보내기** (안드로이드): 기기의 공유 화면으로 쓴 글을 메일 · 메신저 · 쇼핑몰 앱에 넘깁니다. 어디로 보낼지와 "보냈어요"는 사용자가 고릅니다.
- **입금 확인**: 판매자가 약속한 금액과 실제 카드 취소 · 통장 입금을 대조해 차액을 끝까지 따라갑니다.

### 6. 마감일과 알림 (안드로이드)

- 판매자가 정한 기한을 "판매자가 쓴 말 그대로"와 함께 적어 둡니다.
- 마감 3일 전 · 하루 전 · 당일 아침 9시에 알림이 옵니다. 메시지를 보내고 사흘이 지나면 답장이 왔는지 확인하라고 알립니다.
- 알림은 기기 안에서 만들어 띄우고(서버를 거치지 않음), 누르면 그 환불 건이 열립니다. 설정에서 켤 때만 알림 허용을 묻습니다.

### 7. AI 도우미 "말랑이"

- "내 환불 어디까지 왔어?", "독촉 메일 써 줘", "답장 해석해 줘" 같은 말에 답하고, 필요한 화면을 여는 카드를 줍니다.
- 홈에서는 입력칸으로, 내 환불 · 상세에서는 아래 "물어보기" 칸으로, 설정에서는 떠 있는 캐릭터로 엽니다. 상세에서 열면 그 건을 두고 대화합니다.
- 저장하거나 보내는 일은 하지 않습니다. 지난 대화는 이 기기에만 남고, 로그아웃 · 탈퇴 때 지워집니다.
- 서버가 없으면 내 환불 기록으로 기본 안내를 합니다.

### 8. 설정 · 약관

- 화면(언어 · 테마 · 고대비), 마감 알림, 떠 있는 캐릭터 켜고 끄기, 백업, 탈퇴.
- 약관 · 정책 화면: 처리방침 · 이용약관 · 환불 정책 · 쿠키 설정 · 내 정보 삭제. 개인정보 · 접근성 보호 항목 20개를 코드와 짝지어 두었습니다 ([`flutter_app/ARCHITECTURE.md`](../flutter_app/ARCHITECTURE.md)).
- 주민번호 · 통관번호 · 집 주소 · 카드 전체 번호는 받지 않습니다.

### 9. 그 밖에

- **4개 언어**: 홈부터 약관 · 로그인까지 화면 글자가 모두 바뀝니다 (약관 본문과 사업자 정보는 한국어 원문).
- **접근성**: 키보드만으로 이동(Tab, Enter, Alt+1~5), 고대비, 모션 줄이기.
- **연결 상태**: 서버에 붙지 못하면 상단에 한 줄로 알리고 다시 연결할 수 있습니다.
- **안드로이드 뒤로 가기**: 앱을 끄지 않고 한 화면(신청은 한 단계) 뒤로 갑니다.

### 10. 아직 안 된 것

- 앱을 껐다 켜면 다시 로그인해야 합니다.
- iOS가 없고, 사진 · 공유 · 알림은 안드로이드에서만 됩니다.
- 출시용 서명 키와 서버 주소가 정해지지 않았습니다.
- 실제 폰에서는 아직 돌려 보지 않았습니다 (에뮬레이터에서 확인). 사진 찍기와 공유받기의 성공하는 길은 기기에서 확인하지 못했습니다.
- 자세한 목록은 [`flutter_app/README.md`](../flutter_app/README.md)의 "아직 안 된 것".

## 웹

### 1. 첫 화면 (로그인 전)

- **문장 하나 + 버튼 하나 + 실제 화면**으로 시작합니다.
- 그 아래: 다루는 범위와 쇼핑몰 줄 → 서울로 이어지는 3D 지구본 → 스크롤로 넘기는 스마트폰 이야기 → 비교 표 → 5단계 흐름 → 예상 환불 계산기 → 마지막 버튼 띠.
- 쇼핑몰이나 지구본의 항로를 누르면 그 쇼핑몰 · 통화가 채워진 채로 신청이 열립니다.
- 화면 코드를 받는 동안에는 위쪽 줄과 자리 표시가 먼저 보입니다.

### 2. 가입과 로그인

- **이메일 + 비밀번호**로 가입하면 바로 로그인됩니다. **체험 계정**으로 둘러볼 수도 있습니다.
- **이메일 인증**: 가입하면 인증 메일이 갑니다. 인증 전에는 화면 위에 안내 띠와 "다시 받기"가 보이고, 기능은 막지 않습니다.
- **비밀번호를 잊었을 때**: 메일 링크로 새 비밀번호를 정합니다. 오래된 링크면 그 자리에서 새 링크를 받을 수 있습니다.
- 비밀번호 칸에는 보기 버튼이 있습니다.
- **구글 로그인 · 패스키**: 서버에 설정값을 넣으면 로그인 화면에 버튼이 나옵니다. 넣기 전에는 보이지 않습니다. 패스키는 설정에서 등록 · 삭제합니다.

### 3. 환불 신청 (5단계)

| 단계 | 묻는 것 |
|---|---|
| 1 | 어디서 주문하셨나요? (쇼핑몰 · 주문번호) |
| 2 | 어떤 상품인가요? (상품 이름 · 결제 금액) |
| 3 | 어떻게 해결하고 싶으세요? (반품·환불 / 교환 / AS · 문제 설명) |
| 4 | 영수증이나 불량 사진이 있나요? |
| 5 | 마지막으로 확인해 볼까요? |

- **영수증 자동 읽기**: 주문서 파일을 올리면 AI가 읽어 칸을 채웁니다 (AI에 동의한 사용자만).
- 문제 설명을 우리말로 쓰면 쇼핑몰에 보낼 영어로 옮겨 줍니다.
- 사진은 올리기 전에 자를 수 있고, PDF는 미리 볼 수 있습니다. 파일당 10MB.
- 통화 8개: USD · EUR · GBP · JPY · CNY · KRW · CAD · AUD.

### 4. 내 환불

- 통화별로 받을 돈과 실제로 돌아온 돈, 입금 확인 비율을 보여 줍니다.
- 진행 단계로 거르기, 검색(쇼핑몰 · 상품 이름 · 주문번호), 금액순 정렬, 카드로 보기 · 표로 보기.
- **휴지통**: 지운 건을 다시 살릴 수 있습니다.
- 처음 온 사람에게는 빈 화면 안내만 보이고, 검색 결과가 없으면 안내와 "검색어 지우기"가 나옵니다.

### 5. 환불 상세

- **진행 단계**: 서류 준비 → 메시지 준비 → 답변 대기 → 조율 중 → 입금 확인 → 완료. 일부만 들어왔거나 다시 확인이 필요하면 따로 표시합니다.
- 화면마다 "다음에 할 일"을 한 줄로 알려 줍니다.

| 탭 | 하는 일 |
|---|---|
| 메시지 보내기 | AI가 내 상황에 맞게 외국어 메시지를 쓰거나 기본 영문 양식을 불러옴 → 직접 고침 → 저장 → 복사해서 쇼핑몰에 보냄 → "보냈다"고 표시 |
| 답장 · 약속 금액 | 쇼핑몰 답장을 붙여 넣으면 쉬운 우리말로 요약하고 답장 종류를 추천 → 저장. 쇼핑몰이 약속한 금액을 적음 |
| 사진 · 입금 확인 | 영수증 · 사진 보관함. 카드 취소 · 통장 입금을 **직접 확인한 뒤** 날짜 · 금액 · 캡처와 함께 기록 |
| 진행 기록 | 이 건에서 바뀐 일을 시간순으로 |

- 주문 정보나 사진이 바뀌면 예전 메시지는 "다시 저장해 달라"고 알립니다.
- 같은 입금 번호는 두 번 적히지 않습니다.

### 6. 설정

- 내 정보(가입일 · 이메일 인증 여부), 로그아웃.
- **AI 도우미 켜기 · 끄기** (동의와 철회).
- **내 기록 전체 내려받기**.
- **패스키** 등록 · 삭제 (서버에서 켜져 있을 때).
- **회원 탈퇴**: 비밀번호를 확인한 뒤 계정과 모든 사진 · 영수증을 지웁니다.

### 7. AI가 돕는 곳

| 기능 | 어디서 |
|---|---|
| 주문서 읽어서 칸 채우기 | 신청 1단계 |
| 문제 설명을 영어로 | 신청 3단계 |
| 쇼핑몰에 보낼 메시지 쓰기 | 상세 "메시지 보내기" |
| 답장 요약 · 종류 추천 | 상세 "답장 · 약속 금액" |
| 도우미 상담 | 앱 전용 |

- **동의한 사용자만** 쓰고, 결과는 **미리보기**입니다. 사용자가 저장해야 바뀝니다.
- AI가 실패하면 기본 영문 양식으로 대신할 수 있습니다.

### 8. 4개 언어 · 반응형 · 접근성

- 한국어 · 영어 · 일본어 · 중국어. 헤더에서 바꾸고, 첫 화면부터 로그인 뒤 화면 · 입력 오류 문구까지 바뀝니다.
- 휴대폰 폭(390px)을 먼저 맞췄고, 휴대폰에서는 아래쪽 탭으로 이동합니다.
- 본문으로 바로 가기, 탭 · 필터의 상태 읽어 주기, 12px보다 작은 글자 없음, 화면마다 주 버튼 하나.

### 9. 일부러 하지 않는 것

| 하지 않는 것 | 이유 |
|---|---|
| 계좌번호 저장 | 민감한 금융 정보라 보관 부담과 위험이 큼 |
| 환불금을 대신 받아 전달 | 전자금융 관련 등록 · 허가 문제가 생길 수 있음 |
| 은행 · 카드 내역 자동 조회 | 허가와 보안 부담이 큼. 사용자가 확인하고 기록 |
| 쇼핑몰에 메일 대신 보내기 | 잘못 보내면 되돌릴 수 없음. 사용자가 복사해서 보냄 |
| AI 결과 자동 저장 | 틀린 값이 그대로 저장되면 안 됨 |

### 10. 아직 안 된 것 · 확인하지 못한 것

- **구글 로그인**은 실제 구글 계정으로 확인하지 못했습니다 (설정값이 없어 가짜 구글 서버로 시험).
- **패스키**는 크롬의 시험용 가상 장치로만 확인했습니다. 실제 지문 · 얼굴 기기에서는 해 보지 않았습니다.
- 구글로만 가입한 사람은 비밀번호가 없어서, 탈퇴하려면 먼저 "비밀번호를 잊으셨나요?"로 비밀번호를 만들어야 합니다.
- 서버가 만드는 안내 문구 · AI 요약 · 메일 본문은 한국어로만 나옵니다.
- 실제 메일 발송(Resend)은 도메인이 정해진 뒤에 확인합니다. 지금은 시험 서버가 기록에 찍어 주는 링크로 확인했습니다.
- 상용화 전에 필요한 것(배포, 약관 검토, 결제 등)은 루트 [`README.md`](../README.md)의 "다음 할 일".
