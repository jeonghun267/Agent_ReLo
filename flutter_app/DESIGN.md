# ReLo 앱 디자인 규칙

앱 화면을 만들거나 고칠 때 따르는 기준입니다. 숫자는 `lib/core/theme/motion_tokens.dart`와 `lib/core/theme/relo_theme.dart`에 그대로 들어 있습니다.

## 1. 방향

- 홈은 **"광고 페이지"가 아니라 "내 돈이 보이는 통장"**입니다. 처음 쓰는 사람에게는 신청 버튼을, 이미 쓰는 사람에게는 돌려받을 돈과 오늘 할 일을 먼저 보여 줍니다.
- 지구본은 웹과 같은 코드(`shared/widgets/refund_globe.dart`)로 그립니다. 홈에서는 배경으로 은은하게, 신청을 마친 순간에는 앞으로 나와 비행기를 출발시킵니다.
- 사용자에게 개발용 번호나 내부 용어를 보여 주지 않습니다. ("항목 #14", "20/20 적용 완료", "컴플라이언스 센터" 금지)

## 2. 색

| 역할 | 다크 | 라이트 |
|---|---|---|
| 바탕 | `#0F172A` | `#F9FAFB` |
| 카드 | `#1E293B` | `#FFFFFF` |
| 움푹한 면 (입력칸·칩) | `#0B1120` | `#F2F4F6` |
| 본문 글자 | `#F8FAFC` / `#E2E8F0` | `#191F28` / `#242D38` |
| 강조 (버튼·링크) | `#1B64DA` | `#1B64DA` |
| 상태 | 빨강 `#F87171` = 마감 지남·오류. 그 밖의 상태는 색 없이 글자로 | |

- 강조색은 **파랑 하나**입니다. 버튼, 선택 상태, 진행 막대(약속 = 옅은 파랑, 입금 = 진한 파랑)에만 씁니다.
- 초록·주황은 쓰지 않습니다. 색칠한 알약 배지를 여러 개 붙이면 AI가 만든 화면처럼 보이므로, 상태는 `Amazon US · 조건 조율 · D-2`처럼 회색 글자 한 줄로 씁니다. D-day는 굵게만, 마감이 지났을 때만 빨강입니다 (`ReloDdayText`).
- 입금이 끝난 건은 `✓ ¥42,000 들어왔어요`처럼 글자로 알립니다.
- 면은 **테두리 대신 밝기 차이**로 구분합니다. 테두리는 키보드 포커스 링에만 씁니다.

## 3. 모양과 간격

| 항목 | 값 |
|---|---|
| 카드 모서리 | 16 |
| 버튼·입력칸 모서리 | 14 / 12 |
| 칩 | 알약 모양 (999) |
| 화면 좌우 여백 | 20 |
| 간격 단위 | 8 (4, 8, 12, 16, 24, 32) |
| 카드 안 여백 | 16 |
| 하단 탭 높이 | 68 |

## 4. 글자

| 단계 | 크기 / 굵기 | 쓰는 곳 |
|---|---|---|
| 큰 숫자 | 28 / 700, 숫자 폭 고정 | 돌려받을 돈 |
| 제목 | 20 / 800 | 화면 제목, 질문 ("어디서 샀어요?") |
| 소제목 | 16 / 700 | 카드 제목, 구역 제목 |
| 본문 | 14 / 500 | 설명 |
| 보조 | 12 / 500 | 날짜, 주문번호, 캡션 |

- 글꼴은 Pretendard Variable 하나만 씁니다.
- 금액은 `MoneyDisplay`로 그리고, 소수점 아래는 한 단계 작게 둡니다.

## 5. 움직임

| 상황 | 효과 | 시간 / 곡선 |
|---|---|---|
| 앱 시작 | 로고 고리 그리기 → 헤더 자리로 축소 → 홈 등장 | 0 ~ 900ms |
| 탭 전환 | 이전 화면이 사라진 뒤 새 화면이 나타남 (FadeThrough) | 250ms |
| 신청 단계 | 다음은 오른쪽에서, 이전은 왼쪽에서 (SharedAxis) | 300ms |
| 목록 → 상세 | 누른 카드가 그대로 커짐 (OpenContainer) | 350ms |
| 목록 등장 | 카드가 하나씩 아래에서 올라옴 | 항목당 40ms 간격, 320ms |
| 버튼 누름 | 0.97배로 줄고 가벼운 진동 | 100ms |
| 숫자 | 0에서 목표값까지 | 600ms, easeOutCubic |
| 아래 시트 | 아래에서 올라오고 뒤는 어두워짐, 끌어서 닫기 | 300ms |
| 입금 확인·신청 완료 | 축하 효과 한 번 | 1.4s |
| 도우미 캐릭터 | 살짝 떠 있고 한 번 눈 깜빡임, 답을 기다릴 땐 눈이 위를 보고 반짝이가 돎 | 3.6s 반복 |
| 도우미 위치 옮기기 | 끌어 놓으면 가까운 왼쪽·오른쪽 가장자리로 붙음 | 300ms, easeOutBack |

- 시스템의 **모션 줄이기**가 켜져 있으면 지구본 회전과 등장 효과를 끕니다. 상태 변화(색·위치)는 즉시 적용합니다.
- 지구본은 보이지 않는 탭에서는 멈춥니다.

## 6. 문구

- 질문은 짧게: "어디서 샀어요?", "얼마를 돌려받아야 해요?"
- 상태는 사람 말로: "아직 입금 전이에요", "판매자 답장을 기다리는 중".
- 날짜는 남은 날로: `D-2`, `오늘`, `3일 지남`.
- 법 조항, 체크리스트 번호, 영어 약어(WCAG, SDK)는 설정 > 약관·정책 안에서만 씁니다.

## 7. 화면 구성

- 하단 탭 4개: 홈 / 신청 / 내 환불 / 설정. 네 칸 모두 같은 모양(선 아이콘, 선택하면 채운 아이콘)이고, 신청만 튀게 만들지 않습니다. 큰 신청 버튼은 홈 가운데에 있습니다. 약관·정책은 설정 안에 있습니다.
- 도우미 창 왼쪽 위 ☰ = 대화 기록 (도우미 캐릭터 띄우기 + 지난 대화 + 모두 지우기). 대화는 이 기기에만 저장하고, 로그아웃·탈퇴 때 지웁니다.
- 상단에는 로고와 프로필만 둡니다. 언어·테마·고대비는 설정에 있습니다.
- **ReLo 도우미**: 화면 오른쪽 아래(탭 바 위 16)에 떠 있는 52px 캐릭터. 스크롤해도 제자리이고, 끌어서 옮길 수 있고, 키보드가 올라오면 숨습니다. 설정 > 화면에서 끌 수 있습니다. 캐릭터는 로고와 같은 파란 둥근 사각형에 눈·볼·웃는 입(로고 고리의 아래 곡선)과 노란 반짝이를 코드로 그립니다 (`shared/widgets/relo_mascot.dart`).
- 도우미 대화는 아래 시트로 열립니다. 첫 화면은 큰 캐릭터 + "무엇을 도와드릴까요?" + 자주 묻는 질문 5개, 아래는 입력칸과 "AI 답변은 틀릴 수 있어요" 안내. 답 아래에는 버튼 하나(상세 열기·판매자 메시지 쓰기·답장 붙여 넣기·새 환불 신청)만 둡니다. AI는 직접 저장하거나 보내지 않습니다.
- 쿠키 배너는 띄우지 않습니다. 필수 쿠키만 쓰므로 동의 절차가 필요 없고, 분석 도구를 넣을 때 다시 켭니다.
